DripStack

A Technical Lifecycle Communication Platform — event-triggered, branching drip sequences of technical communications to technicians during incident resolution and onboarding.

DripStack ingests an event (a Metasys/Sentry/API error), matches it to a sequence, and a durable Temporal workflow drives a multi-step, branching conversation with the technician: syntax-highlighted code, pretty-printed JSON, collapsible logs, AI plain-language error explanations, and action buttons (resolve / I need help) — over email, Slack, and Teams.

New here? Jump to the Quickstart to run the whole platform locally in a few minutes, fully keyless.

What's inside

Durable workflows

One Temporal workflow per run — durable timers survive restarts; signals (button clicks) race timeouts deterministically.

Production integrations

Email via Resend & AWS SES, native Slack/Teams delivery, signed outbound webhooks, and OIDC SSO.

RBAC + multi-tenancy

Strict per-org isolation, permission-gated endpoints, platform vs. customer tiers, and an append-only audit log.

Secure by default

HMAC-signed links, POST-confirmed actions, bound redirects, security headers, and a production secret guard.
