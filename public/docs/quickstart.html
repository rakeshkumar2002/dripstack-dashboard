Quickstart

Run the entire platform locally — keyless — in a few minutes.

Prerequisites

  • Docker Desktop (Postgres, RabbitMQ, Temporal dev server)
  • uv — curl -LsSf https://astral.sh/uv/install.sh | sh
  • Node 20+ & pnpm — corepack enable pnpm

1 · Configure

cp .env.example .env

The defaults run everything in keyless mode (email renders to a local preview, AI degrades to a fallback). See Configuration for every variable.

2 · Start infrastructure

docker compose up -d
# Postgres :5432 · RabbitMQ + UI :15672 · Temporal + UI :8233

3 · Create the schema & seed

# in the dripstack-backend repo
uv sync
uv run alembic upgrade head
uv run seed          # prints demo logins + writes scripts/.demo-env

4 · Run the backend

Two shells, both from backend/:

uv run api           # FastAPI on :4000
uv run worker        # Temporal worker + RabbitMQ consumers

5 · Run the dashboard

pnpm dev   # Next.js on :3000  (in dripstack-dashboard)

6 · Fire the sample event

./scripts/fire-demo-event.sh

Watch it flow

SurfaceURL
Rendered email (log provider)http://localhost:4000/dev/emails
Dashboard (login prefilled)http://localhost:3000
Temporal Web UIhttp://localhost:8233
RabbitMQ UIhttp://localhost:15672

Open the Step-1 email, then click Mark as resolved or I need help. Each action shows a confirmation page (a deliberate anti-prefetch guard) and the POST drives the workflow: resolve ends the run resolved; I need help (or the waitForAction timeout) advances to the escalation step.

Demo logins — Customer admin: demo@dripstack.dev / DripStackDemo!23; Platform/integration: integration@dripstack.dev / IntegrationDemo!23.

Tests & lint

# in the dripstack-backend repo
uv run pytest                 # full suite (unit + DB + time-skipping workflow)
uv run ruff check src tests
