API reference

All endpoints are served from your DripStack base URL. Authenticated requests send Authorization: Bearer <accessToken>. Responses are camelCase JSON; datetimes are ISO-8601 UTC with a trailing Z.

Interactive OpenAPI docs are available at /docs (Swagger) and /redoc when the API is running.

System

MethodPathDescription
GET/healthLiveness probe.
GET/readyReadiness probe — 503 until the DB is reachable.

Auth

MethodPathDescription
POST/api/v1/auth/registerCreate an organization + admin user.
POST/api/v1/auth/loginEmail + password → access & refresh tokens (audited).
POST/api/v1/auth/refreshExchange a refresh token for new tokens.
GET/api/v1/auth/meCurrent principal: role, scope, permissions, organization.

SSO (OIDC)

MethodPathDescription
GET/api/v1/ssoMasked SSO config. integrations.read
PUT/api/v1/ssoCreate/update the OIDC connection. integrations.write
DEL/api/v1/ssoRemove the connection. integrations.write
GET/api/v1/auth/sso/{org}/startBegin the login flow → redirect to the IdP.
GET/api/v1/auth/sso/callbackOIDC redirect URI → issues DripStack tokens.

Ingest

MethodPathDescription
POST/api/v1/ingest/{eventSourceId}Public, HMAC-signed inbound webhook. Rate-limited 120/min.
POST/api/v1/eventsAuthenticated event ingest via API key (x-api-key).

Tracking (signed links)

MethodPathDescription

GET/r/{runId}/log/{blockId}Full syntax-highlighted log/JSON/code view.
